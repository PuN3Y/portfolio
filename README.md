# portfolio

This repository contains a number of Python Notebooks of me exploring and manipulating different datasets. These are all projects (a mix of guided and unguided) hosted within Dataquest to help self-educators learn and implement key principles of data science using Python, Spark, and SQL.

In summary, please find details of each project below:

- `Analysing Wikipedia Pages`: A project in which we explore the use case of multi-processing on a generally randomised dataset _(a 1000 MB subset of Wikipedia pages)_, and explore creating our own .py files to allow efficient for efficient operations. In this project, we utilise the `os`, `time`, `math`, `functools`, `importlib`, `multiprocessing`, and `itertools` libraries.


- `App Data` A project about finding the ideal profiles for an app in order for it to be profitable. To achieve this, we use native Python functions for preliminary data cleaning and datta analysis to understand the data landscape between the Apple App Store, and the Google Play Store. In this project, we utilise the `csv` library.
