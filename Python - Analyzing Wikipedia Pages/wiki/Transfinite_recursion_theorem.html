Mathematical theorem

In mathematics, the transfinite recursion theorem says a function can be defined using a recursion over a well-ordered set; for example, N {\displaystyle \mathbb {N} } but also over general well-ordered sets.

Since each well-ordered set is isomorphic to an ordinal, the theorem is also often stated in terms of ordinals.

Statements

[edit]

Transfinite recursion is an instance of transfinite induction and the latter works over a well-ordered set (in fact, the feasibility of such an induction is equivalent to well-ordered-ness). In particular, the theorem can be stated for well-ordered sets. If A {\displaystyle A} is a partially ordered set, we write A a = { b ∈ A ∣ b < a } . {\displaystyle A^{a}=\{b\in A\mid b<a\}.}

Transfinite recursion theorem [1]—Let a set X {\displaystyle X} , a well-ordered set A {\displaystyle A} and a function

G : { A a → X ∣ a ∈ A } → X {\displaystyle G:\{A^{a}\to X\mid a\in A\}\to X}

be given. Then there exists a unique function

f : A → X {\displaystyle f:A\to X}

such that

f ( a ) = G ( f | A a ) {\displaystyle f(a)=G(f|_{A^{a}})}

for each a {\displaystyle a} in A {\displaystyle A} , where the vertical bar means restriction.

The transfinite recursion theorem is also commonly stated for ordinals. One simple version is: let a set X {\displaystyle X} and a class function G {\displaystyle G} with values in X {\displaystyle X} defined on the class of all functions be given. Then, for each ordinal α {\displaystyle \alpha } , there exists a unique function

f : α → X {\displaystyle f:\alpha \to X}

such that, for every ordinal β < α {\displaystyle \beta <\alpha } ; that is, β ∈ α {\displaystyle \beta \in \alpha } or β ⊊ α {\displaystyle \beta \subsetneq \alpha } ,

f ( β ) = G ( f | β ) {\displaystyle f(\beta )=G(f|_{\beta })} .

Since an ordinal is a well-ordered set, the above version follows from the well-ordered version (as β = α β {\displaystyle \beta =\alpha ^{\beta }} ). Although it is common to ask G {\displaystyle G} to be defined for all functions, this is just a convenient way of stating the theorem. In practice, one usually only defines G ( f ) {\displaystyle G(f)} for functions f : α → X {\displaystyle f:\alpha \to X} , α {\displaystyle \alpha } all ordinals, and then extends G {\displaystyle G} for all other functions arbitrary.

Proof

[edit]

When A = N {\displaystyle A=\mathbb {N} } , the proof here appears in N. Jacobson's Basic Algebra I[2] and exactly the same proof goes through for an arbitrary well-ordered set. The proof itself is taken from Halmos.[1]

We say a subset E ⊂ A × X {\displaystyle E\subset A\times X} is closed (with respect to G {\displaystyle G} ) if for each function f : A a → X , a ∈ A {\displaystyle f:A^{a}\to X,\,a\in A} whose graph is contained in E {\displaystyle E} , we have ( a , G ( f ) ) {\displaystyle (a,G(f))} is in E {\displaystyle E} . For example, A × X {\displaystyle A\times X} is closed.

Let F {\displaystyle F} be the intersection of all closed subsets of A × X {\displaystyle A\times X} (with respect to G {\displaystyle G} ), which is again closed. We shall prove F {\displaystyle F} is a graph of a function A → X {\displaystyle A\to X} ; that is, the fiber p − 1 ( a ) {\displaystyle p^{-1}(a)} for the projection p : F ⊂ A × X → A {\displaystyle p:F\subset A\times X\to A} has exactly one element for each a {\displaystyle a} in A {\displaystyle A} . For this, we shall use strong induction over A {\displaystyle A} . That is, assuming # p − 1 ( b ) = 1 {\displaystyle \#p^{-1}(b)=1} for every b < a {\displaystyle b<a} , we show # p − 1 ( a ) = 1 {\displaystyle \#p^{-1}(a)=1} .

By inductive hypothesis, we have the function f : A a → X , b ↦ unique element in  p − 1 ( b ) {\displaystyle f:A^{a}\to X,\,b\mapsto {\text{unique element in }}p^{-1}(b)} . Note the graph of it lies in F {\displaystyle F} . Since F {\displaystyle F} is closed, ( a , G ( f ) ) {\displaystyle (a,G(f))} is in F {\displaystyle F} . Thus, # p − 1 ( a ) ≥ 1 {\displaystyle \#p^{-1}(a)\geq 1} . To show it is the equality, suppose otherwise. That means there is some pair ( a , y ) ≠ ( a , G ( f ) ) {\displaystyle (a,y)\neq (a,G(f))} in F {\displaystyle F} . We claim the set

E := F − { ( a , y ) } {\displaystyle E:=F-\{(a,y)\}}

is closed. Thus, let g : A b → X {\displaystyle g:A^{b}\to X} be a function whose graph lies in E {\displaystyle E} . If b = a {\displaystyle b=a} , then we have f = g {\displaystyle f=g} by inductive hypothesis; indeed, since their graphs lie in F {\displaystyle F} ,

{ f ( c ) , g ( c ) } ⊂ p − 1 ( c ) {\displaystyle \{f(c),g(c)\}\subset p^{-1}(c)}

for each c < a {\displaystyle c<a} . Thus, ( b , G ( g ) ) ∈ E {\displaystyle (b,G(g))\in E} since y ≠ G ( f ) = G ( g ) {\displaystyle y\neq G(f)=G(g)} and F {\displaystyle F} is closed. If b ≠ a {\displaystyle b\neq a} , then again ( b , G ( g ) ) {\displaystyle (b,G(g))} is in E {\displaystyle E} as F {\displaystyle F} is closed. This proves the claim and then E ⊊ F {\displaystyle E\subsetneq F} is a contradiction to the smallest-ness of F {\displaystyle F} . Finally, the uniqueness holds by a similar but easier induction. ◻ {\displaystyle \square }

Examples

[edit]

Example: a basis construction

[edit]

Let V {\displaystyle V} be a vector space. There is a "very obvious" way to construct a basis of V {\displaystyle V} as follows. If V ≠ 0 {\displaystyle V\neq 0} , pick a nonzero vector v 1 {\displaystyle v_{1}} and then pick another nonzero vector v 2 {\displaystyle v_{2}} not in the span of v 1 {\displaystyle v_{1}} , if any, and so on. Transfinite recursion can make this argument rigorous, as we now show (alternatively, one can use Zorn's lemma; see Zorn's lemma § Every vector space has a basis.)

Let the above V {\displaystyle V} be given a well-ordering by the well-ordering theorem. Suppose we are given a sequence of vectors x γ {\displaystyle x_{\gamma }} indexed by an ordinal β {\displaystyle \beta } . That is, we are given a function f : β → V {\displaystyle f:\beta \to V} such that f ( γ ) = x γ {\displaystyle f(\gamma )=x_{\gamma }} for each γ ∈ β {\displaystyle \gamma \in \beta } (or γ < β {\displaystyle \gamma <\beta } ). Then let

G ( f ) = {\displaystyle G(f)=} the least element in the complement V − span ⁡ ( im ⁡ ( f ) ) {\displaystyle V-\operatorname {span} (\operatorname {im} (f))}

if V ≠ span ⁡ ( im ⁡ ( f ) ) {\displaystyle V\neq \operatorname {span} (\operatorname {im} (f))} and G ( f ) = 0 {\displaystyle G(f)=0} otherwise. Note, since f {\displaystyle f} is arbitrary, the image of f {\displaystyle f} is not necessarily linearly independent; all we have is that G ( f ) {\displaystyle G(f)} is linearly independent from the nonzero vectors in im ⁡ ( f ) {\displaystyle \operatorname {im} (f)} .

The transfinite recursion theorem then says: given an ordinal α {\displaystyle \alpha } , there exists a unique f : α → V {\displaystyle f:\alpha \to V} that satisfies the recursion condition; i.e., f ( β ) = G ( f | β ) {\displaystyle f(\beta )=G(f|_{\beta })} is linearly independent from im ⁡ ( f | β ) {\displaystyle \operatorname {im} (f|_{\beta })} for β < α {\displaystyle \beta <\alpha } . In particular, the nonzero vectors in the image of f {\displaystyle f} are linearly independent. Finally, if we take α = κ {\displaystyle \alpha =\kappa } to be some large ordinal; e.g., take κ {\displaystyle \kappa } to have cardinality strictly larger than that of V {\displaystyle V} , then, for the reason of cardinality,

B := im ⁡ ( f : κ → V ) − { 0 } {\displaystyle B:=\operatorname {im} (f:\kappa \to V)-\{0\}}

is a basis of V {\displaystyle V} . (Note, unlike a construction by Zorn's lemma, this basis is uniquely determined by a choice of a well-ordering on V {\displaystyle V} .)

Example: a proof of Zorn's lemma

[edit]

Transfinite recursion is used in a typical proof of Zorn's lemma, assuming the axiom of choice. Here is an argument (which is fairly similar to the construction of a basis above).[3]

Let X {\displaystyle X} be a partially ordered set in which each chain, including the empty chain, has an upper bound. To show X {\displaystyle X} has a maximal element, suppose, on the contrary, that it has none. Then each chain C {\displaystyle C} has a strict upper bound; i.e., an element x {\displaystyle x} in X {\displaystyle X} such that x > y {\displaystyle x>y} for each y {\displaystyle y} in C {\displaystyle C} , since it has an upper bound which is bounded by some strictly larger element. Let c : P ( X ) − { ∅ } → X {\displaystyle c:{\mathfrak {P}}(X)-\{\emptyset \}\to X} be a choice function; i.e., c ( S ) ∈ S {\displaystyle c(S)\in S} and then for each chain C {\displaystyle C} in X {\displaystyle X} , let

b ( C ) = c ( { strict upper bounds of  C } ) . {\displaystyle b(C)=c(\{{\text{strict upper bounds of }}C\}).}

We now recursively construct a sequence over ordinals. For each function f : β → X {\displaystyle f:\beta \to X} , let G ( f ) = b ( im ⁡ ( f ) ) {\displaystyle G(f)=b(\operatorname {im} (f))} if im ⁡ ( f ) {\displaystyle \operatorname {im} (f)} is a chain and otherwise G ( f ) = {\displaystyle G(f)=} some arbitrary element in X {\displaystyle X} ; e.g., b ( ∅ ) {\displaystyle b(\emptyset )} . By the transfinite recursion theorem, we find a function f : α → X {\displaystyle f:\alpha \to X} such that f ( β ) = G ( f | β ) {\displaystyle f(\beta )=G(f|_{\beta })} for β < α {\displaystyle \beta <\alpha } ; in particular, it is injective. But this is a contradiction since there is an ordinal whose cardinality is strictly larger than that of X {\displaystyle X} (see Hartogs number). If one is not sure about the existence of a large ordinal, there is also an argument that avoids ordinals altogether (still using transfinite recursion). See e.g., Hausdorff maximal principle § Proof from the well-ordering theorem. ◻ {\displaystyle \square }

Recursion with the axiom of replacement

[edit]
See also: Well-founded relation § Induction and recursion

For some use of transfinite recursion, we may need to construction a function with values in a class; in that case, we need to use the axiom of replacement to ensure we still get the function f {\displaystyle f} even though the codomain is a class.

Here is an example of such a need.[4][5] Suppose we want to show

Each well-ordered set is uniquely isomorphic to a unique ordinal.

The problem is that, a priori, we don’t know what ordinal to use. Thus, at each stage in transfinite induction, we construct a new ordinal. Precisely, given a well-ordered set X {\displaystyle X} and an element a {\displaystyle a} in X {\displaystyle X} , suppose we have constructed

g b : X b → ∼ α b {\displaystyle g_{b}:X^{b}{\overset {\sim }{\to }}\alpha _{b}}

where X b = { c ∣ c < b } {\displaystyle X^{b}=\{c\mid c<b\}} . We shall extend these isomorphisms to an isomorphism X a ≃ α {\displaystyle X^{a}\simeq \alpha } for some ordinal α {\displaystyle \alpha } . If a = s ( b ) {\displaystyle a=s(b)} is a successor; i.e., the least element among strict upper bounds of b {\displaystyle b} , then we let f | X b = g b {\displaystyle f|_{X^{b}}=g_{b}} and f ( a ) = α b {\displaystyle f(a)=\alpha _{b}} . Then

f : X a → ∼ s ( α b ) := α b ∪ { α b } , {\displaystyle f:X^{a}{\overset {\sim }{\to }}s(\alpha _{b}):=\alpha _{b}\cup \{\alpha _{b}\},}

where the union on the right exists by the axiom of union. If a = sup ( X a ) {\displaystyle a=\sup(X^{a})} , then, thinking g b {\displaystyle g_{b}} as sets of ordered pairs, let

f = ⋃ b < a g b . {\displaystyle f=\bigcup _{b<a}g_{b}.}

The union on the right is a set by the axiom of replacement and the axiom of union; indeed, the former guarantees the collection { g b ∣ b < a } {\displaystyle \{g_{b}\mid b<a\}} is a set. Let α {\displaystyle \alpha } be the image of f {\displaystyle f} , which is clearly an ordinal, and f : X a → ∼ α {\displaystyle f:X^{a}{\overset {\sim }{\to }}\alpha } . Finally, we check the uniqueness. By transfinite induction, we see isomorphisms between ordinals are the identities. Then given f : X → ∼ α , g : X → ∼ β {\displaystyle f:X{\overset {\sim }{\to }}\alpha ,g:X{\overset {\sim }{\to }}\beta } , we have g ∘ f − 1 : α → ∼ β {\displaystyle g\circ f^{-1}:\alpha {\overset {\sim }{\to }}\beta } is the identity and so f = g {\displaystyle f=g} . ◻ {\displaystyle \square }

The same argument can be used to prove the transfinite recursion theorem when the target X {\displaystyle X} is a class. The proof is by strong induction over ordinals (the same proof works for well-ordered sets but we use ordinals for simplicity). Thus, assume the theorem is true for every β < α {\displaystyle \beta <\alpha } . By inductive hypothesis, for each β < α {\displaystyle \beta <\alpha } , we have a unique function g β : β → X {\displaystyle g_{\beta }:\beta \to X} satisfying the recursion condition. Let h β : β → X {\displaystyle h_{\beta }:\beta \to X} be given by γ ↦ G ( g β | γ ) {\displaystyle \gamma \mapsto G(g_{\beta }|_{\gamma })} . In the limit case; i.e., α {\displaystyle \alpha } is a limit ordinal, identifying functions with their graphs, consider the union

⋃ β < α h β . {\displaystyle \bigcup _{\beta <\alpha }h_{\beta }.}

The formation of a union is justified by the axiom of union but for the above union to be a set, we need the collection

{ h β ∣ β < α } {\displaystyle \{h_{\beta }\mid \beta <\alpha \}}

to be a set; in other words, the image of the map β ↦ h β {\displaystyle \beta \mapsto h_{\beta }} to be a set and that is ensured by the axiom of replacement. Finally, this union is the graph of a function f : α → X {\displaystyle f:\alpha \to X} that satisfies the required recursion condition. The successor case is handled similarly. ◻ {\displaystyle \square }
