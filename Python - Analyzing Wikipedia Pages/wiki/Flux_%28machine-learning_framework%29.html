Flux is an open-source machine-learning software library and ecosystem written in Julia.[1][7] Its current stable release is v0.16.5[5] . It has a layer-stacking-based interface for simpler models, and has a strong support on interoperability with other Julia packages instead of a monolithic design.[8] For example, GPU support is implemented transparently by CuArrays.jl.[9] This is in contrast to some other machine learning frameworks which are implemented in other languages with Julia bindings, such as TensorFlow.jl (the unofficial wrapper, now deprecated), and thus are more limited by the functionality present in the underlying implementation, which is often in C or C++.[10] Flux joined NumFOCUS as an affiliated project in December of 2021.[11]

Flux's focus on interoperability has enabled, for example, support for Neural Differential Equations, by fusing Flux.jl and DifferentialEquations.jl into DiffEqFlux.jl.[12][13]

Flux supports recurrent and convolutional networks. It is also capable of differentiable programming[14][15][16] through its source-to-source automatic differentiation package, Zygote.jl.[17]

Julia is a popular language in machine-learning[18] and Flux.jl is its most highly regarded machine-learning repository[18] (Lux.jl is another more recent, that shares a lot of code with Flux.jl). A demonstration[19] compiling Julia code to run in Google's tensor processing unit (TPU) received praise from Google Brain AI lead Jeff Dean.[20]

Flux has been used as a framework to build neural networks that work with homomorphic encrypted data without ever decrypting it.[21][22] This kind of application is envisioned to be central for privacy to future API using machine-learning models.[23]

Flux.jl is an intermediate representation for running high level programs on CUDA hardware.[24][25] It was the predecessor to CUDAnative.jl which is also a GPU programming language.[26]
